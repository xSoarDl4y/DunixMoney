# MONEYFLOW Mobile

Ứng dụng khởi đầu bằng Expo + React Native.

```bash
pnpm install
pnpm dev:mobile
```

Mở Expo Go hoặc simulator theo hướng dẫn trên terminal.

Hiện tại đây là giao diện MVP với dữ liệu trong bộ nhớ của ứng dụng. Chưa có đăng nhập, database cục bộ, đồng bộ API hoặc push notification.
